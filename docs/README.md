# Abacus: A Python Command-Line Calculator

Abacus is a Python-based command-line calculator designed to solve a diverse range of mathematical problems across various fields. The tool offers an interactive and user-friendly menu system, allowing users to select specific operations and perform calculations efficiently.

## Features

### Core Features

Basic Arithmetic Operations: Addition, Subtraction, Multiplication, Division.

Input Handling: Accept numeric inputs and validate user entries to ensure proper functionality.

Output Results: Clear and formatted output displaying results of calculations.

Error Handling: Gracefully handle division by zero, invalid operations, and non-numeric inputs.

### Extended Features

Advanced Operations: Modulus, Exponentiation, and Floor Division for enhanced mathematical calculations.

Multiple Calculations: Perform multiple calculations in a single session without restarting the application.

Calculation History: Maintain a session-based history of calculations, retrievable upon user request.

Clear Screen Option: An option to declutter the interface during extended sessions.

### Miscellaneous Advanced Features

Interactive Menu: A structured menu displaying available operations and their descriptions for easy navigation.

Save History to File: Export the session’s calculation history to a text file for future reference.

Scientific Calculator Features: Support for advanced mathematical functions like square root, logarithms, and trigonometric calculations (e.g., sin, cos, tan).

Customizable Precision: Set the number of decimal places for more accurate results.

Exit Option: A seamless way to exit the program.
